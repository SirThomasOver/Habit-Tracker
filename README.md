# 🧠 Habit Tracker

Um sistema de acompanhamento de hábitos desenvolvido em Python.

O objetivo do projeto é permitir que o usuário cadastre hábitos, defina metas e frequências e acompanhe sua consistência ao longo do tempo por meio de registros e histórico.

---

## 🎯 Objetivo

O projeto busca transformar o acompanhamento de hábitos em um processo simples e mensurável.

Em vez de registrar apenas se um hábito foi realizado ou não, o sistema também considera **a intensidade da realização**.

Por exemplo:

> Meta: estudar Python por 30 minutos.

O usuário pode registrar:

- 0 minutos → não realizou
- 15 minutos → realizou parcialmente
- 30 minutos → atingiu a meta
- 60 minutos → ultrapassou a meta

Dessa forma, o sistema consegue acompanhar não apenas a frequência, mas também o nível de realização de cada hábito.
